# AI Pop Optimizer — All in One

Performance-мод для Stellaris 4.5, объединяющий лучшие идеи существующих модов и исправляющий их главную ошибку: **ИИ не слабеет при ограничении попов**.

## Принцип (4 компонента)

1. **Кэп попов у ИИ** — `common/scripted_triggers/apo_triggers.txt` + ежемесячный пульс в `events/apo_monthly.txt`: при превышении порога (по умолчанию 200) рост органики/сборки на ИИ-планетах обнуляется через статические модификаторы.
2. **Компенсация экономики ИИ** — `common/static_modifiers/apo_static_modifiers.txt`: ИИ получает растущий с числом планет бонус к производству (`pop_ultraction`-независимые модификаторы), чтобы при меньшем числе попов держать ванильную силу. Бонусы применяются только к `is_ai = yes` странам.
3. **Упрощение вакансий** — ИИ-планетам запрещается спамить хабитаты и лишние типы районов (`apocalypse-style district weights` в AI планировке не переопределяем, вместо этого `on_actions`-фильтр).
4. **Уборка мусорных сущностей** — отключение ксеносовместимости для ИИ, лимит суб-видов (через `species_rights` ограничение), автоудаление 0/x флотов ИИ.

## Структура

```
.metadata/metadata.json       — манифест (для Workshop)
common/scripted_triggers/     — условия (is_ai, планетарные пороги)
common/scripted_effects/       — эффекты (apply/снятие модификаторов)
common/static_modifiers/      — сами модификаторы (кэп-рост, компенсация)
common/on_actions/           — хуки (on_monthly_pulse, on_game_start)
events/apo_monthly.txt        — ежемесячный обработчик
common/defines/               — (план) tunables: кэп, шаг компенсации
```

## Конфигурация

Все цифры вынесены в начало `events/apo_monthly.txt` (массив `apo_constants`), чтобы калибровать баланс без spelunking по файлам.

## Trade-offs (честно)

- Мод для **одиночной игры**. В мультиплеере несимметричные бонусы ИИ неважны, но мод всё равно менять ничего не сломает — просто не даёт эффекта в MP-симметрии.
- Кэп попов = «ферма» для игрока при агрессивной войне. Компенсация производства смягчает, но не устраняет.
- Тестировать на длинных партиях (до 2500+ года) на большой галактике.
